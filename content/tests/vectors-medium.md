:::question{type=single}
Чему равно скалярное произведение перпендикулярных векторов?

- [x] Нулю
- [ ] Произведению модулей
- [ ] Сумме модулей
- [ ] Бесконечности

:::explanation
$\vec{a} \cdot \vec{b} = ab\cos\varphi$, а $\cos 90° = 0$. Поэтому работа силы, перпендикулярной перемещению (например, силы реакции опоры при горизонтальном движении), равна нулю.
:::
:::

:::question{type=single}
Чему равно скалярное произведение вектора на самого себя?

- [x] Квадрату его модуля
- [ ] Самому вектору
- [ ] Нулю
- [ ] Модулю вектора

:::explanation
$\vec{a} \cdot \vec{a} = a \cdot a \cdot \cos 0° = a^2$. Величина $\vec{a}\cdot\vec{a}$ называется скалярным квадратом вектора.
:::
:::

:::question{type=single}
Чему равна работа равнодействующей двух сил?

- [x] Сумме работ каждой из сил в отдельности
- [ ] Произведению работ
- [ ] Работе большей из сил
- [ ] Нулю

:::explanation
По дистрибутивности скалярного произведения: $(\vec{F}_1 + \vec{F}_2)\cdot\vec{s} = \vec{F}_1\cdot\vec{s} + \vec{F}_2\cdot\vec{s}$. Силы складываются векторно, а работы — алгебраически.
:::
:::

:::question{type=single}
Какое свойство скалярного произведения НЕ выполняется «полноценно»?

- [x] Ассоциативность: $(\vec{a} \cdot \vec{b})\cdot\vec{c} \ne \vec{a} \cdot (\vec{b} \cdot \vec{c})$
- [ ] Коммутативность
- [ ] Дистрибутивность
- [ ] Ассоциативность при умножении на скаляр

:::explanation
Выражение $\vec{a}\cdot\vec{b}\cdot\vec{c}$ некорректно: скаляр нельзя умножать скалярно на вектор так же «в лоб». А вот $(\lambda\vec{a})\cdot\vec{b} = \lambda(\vec{a}\cdot\vec{b})$ — можно.
:::
:::

:::question{type=single}
Зачем второй закон Ньютона для маятника $m\vec{a} = m\vec{g} + \vec{T} + \vec{f}$ проектируют на ось?

- [x] Чтобы перейти от векторного равенства к скалярным уравнениям для проекций
- [ ] Чтобы избавиться от векторов навсегда
- [ ] Чтобы найти массу маятника
- [ ] Чтобы сократить силы

:::explanation
Проектируя, получаем $ma_x = mg_x + T_x + f_x$: обе операции — сложение и последующее проектирование — стандартно проносятся через равенство благодаря двум свойствам проектирования.
