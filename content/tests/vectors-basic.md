:::question{type=single}
Что такое скалярная физическая величина?

- [x] Величина, для задания которой достаточно одного числа с размерностью
- [ ] Величина, имеющая модуль и направление
- [ ] Любое число без единиц измерения
- [ ] Величина, задаваемая тремя числами

:::explanation
Скаляр задаётся одним числом: масса 3 кг, температура −10 °C, напряжение 220 В. Складывать можно только скаляры одинаковой размерности.
:::
:::

:::question{type=single}
Что такое векторная физическая величина?

- [x] Величина, характеризуемая неотрицательным скаляром (модулем) и направлением в пространстве
- [ ] Величина, задаваемая одним числом
- [ ] Число без размерности
- [ ] Величина, имеющая только модуль

:::explanation
Скорость 60 км/ч — информация неполная: важно и направление движения. Сила 100 Н опять-таки нуждается в указании направления. Вектор — направленный отрезок, его длина в масштабе — модуль.
:::
:::

:::question{type=multiple}
Какие из перечисленных величин являются векторами?

- [x] Скорость
- [x] Сила
- [x] Перемещение
- [ ] Масса
- [ ] Температура

:::explanation
Скорость, сила и перемещение имеют модуль и направление. Масса и температура — скаляры: их задаёт одно число.
:::
:::

:::question{type=single}
Что такое модуль вектора?

- [x] Его абсолютная величина — неотрицательный скаляр
- [ ] Его направление
- [ ] Сумма координат вектора
- [ ] Квадрат длины вектора

:::explanation
Модуль вектора — длина стрелки. Буква без стрелки (например, $v$ вместо $\vec{v}$) обозначает модуль соответствующего вектора.
:::
:::

:::question{type=single}
Какой вектор называется нулевым?

- [x] Вектор, начало и конец которого совпадают; он не имеет определённого направления
- [ ] Вектор единичной длины
- [ ] Вектор, перпендикулярный оси
- [ ] Любой неподвижный вектор

:::explanation
Нулевой вектор $\vec{0}$ — это просто точка; его длина равна нулю, а направление не определено.
:::
:::

:::question{type=single}
Какие векторы называются коллинеарными?

- [x] Лежащие на одной прямой или на параллельных прямых
- [ ] Пересекающиеся под прямым углом
- [ ] Имеющие общее начало
- [ ] Имеющие равные модули

:::explanation
Коллинеарные векторы сонаправлены, если их направления совпадают, и противоположно направлены, если направления различны.
:::
:::

:::question{type=single}
Когда два вектора равны?

- [x] Когда они сонаправлены и имеют равные модули
- [ ] Когда их начала совпадают
- [ ] Когда их концы совпадают
- [ ] Когда угол между ними равен нулю

:::explanation
Равенство векторов не требует совпадения начал и концов: вектор можно переносить параллельно самому себе, и получится равный ему вектор.
:::
:::

:::question{type=single}
Как складываются два вектора по правилу треугольника?

- [x] Начало второго вектора помещается в конец первого; сумма соединяет начало первого с концом второго
- [ ] Начала векторов помещаются в одну точку, сумма — диагональ параллелограмма
- [ ] Складываются модули векторов
- [ ] Складываются проекции векторов

:::explanation
Правило треугольника следует из сложения перемещений: тело совершило перемещение $\vec{s}_1$ из A в B, затем $\vec{s}_2$ из B в C; итоговое перемещение — вектор $\vec{s}_1 + \vec{s}_2$ из A в C.
:::
:::

:::question{type=single}
Как складываются векторы по правилу параллелограмма?

- [x] Начала векторов помещаются в одну точку; сумма — диагональ параллелограмма, построенного на этих векторах
- [ ] Начало второго помещается в конец первого
- [ ] Сумма — отрезок между концами векторов
- [ ] Складываются углы между векторами

:::explanation
Совместное действие сил $\vec{F}_1$ и $\vec{F}_2$ эквивалентно действию равнодействующей $\vec{F}$, служащей диагональю параллелограмма. Оба правила дают один и тот же результат.
:::
:::

:::question{type=single}
Какие векторы разрешается складывать в физике?

- [x] Только векторы одинаковой размерности
- [ ] Любые векторы
- [ ] Только коллинеарные
- [ ] Только векторы с общим началом

:::explanation
Скорость складывается со скоростью, сила — с силой, но сложить вектор скорости с вектором силы нельзя: размерности различны.
:::
:::

:::question{type=single}
Что такое вектор, противоположный данному?

- [x] Вектор, равный по модулю данному и направленный противоположно
- [ ] Вектор, перпендикулярный данному
- [ ] Нулевой вектор
- [ ] Вектор с вдвое большим модулем

:::explanation
Сумма вектора и противоположного ему равна нулю: $\vec{a} + (-\vec{a}) = \vec{0}$.
:::
:::

:::question{type=single}
Как определяется разность векторов $\vec{a} - \vec{b}$?

- [x] Как сумма $\vec{a} + (-\vec{b})$; геометрически — отрезок между концами векторов, направленный к «уменьшаемому»
- [ ] Как сумма модулей векторов
- [ ] Как отрезок между началами векторов
- [ ] Разность векторов не определена

:::explanation
Приводим векторы к одному началу, соединяем концы и «укалываем» тот вектор, из которого вычитаем — правило «уколоть уменьшаемое».
:::
:::

:::question{type=single}
Каким законом обладает сложение векторов при перестановке слагаемых?

- [x] Коммутативностью: $\vec{a} + \vec{b} = \vec{b} + \vec{a}$
- [ ] Дистрибутивностью
- [ ] Ассоциативностью
- [ ] Закона перестановки нет

:::explanation
Какая разница, в каком порядке суммировать векторы, если диагональ параллелограмма одна и та же? Сложение векторов коммутативно и ассоциативно: $(\vec{a} + \vec{b}) + \vec{c} = \vec{a} + (\vec{b} + \vec{c})$.
:::
:::

:::question{type=single}
Какой вектор получается при умножении вектора на отрицательный скаляр?

- [x] Вектор с модулем, умноженным на модуль скаляра, и противоположным направлением
- [ ] Нулевой вектор
- [ ] Вектор только с изменённым модулем
- [ ] Скалярная величина

:::explanation
Вектор $-2\vec{a}$ вдвое длиннее вектора $\vec{a}$ и направлен противоположно. Разделить вектор на скаляр $\lambda \ne 0$ — значит умножить его на $1/\lambda$.
:::
:::

:::question{type=single}
Какое действие не меняет вектора?

- [x] Умножение на единицу
- [ ] Умножение на нуль
- [ ] Сложение с противоположным вектором
- [ ] Умножение на минус единицу

:::explanation
$1 \cdot \vec{a} = \vec{a}$. Умножение на нуль даёт нулевой вектор, прибавление противоположного вектора даёт нуль, а умножение на $-1$ меняет направление.
:::
:::

:::question{type=single}
Какой физический закон записывается как произведение скаляра на вектор?

- [x] Второй закон Ньютона: $m\vec{a} = \vec{F}$
- [ ] Закон всемирного тяготения
- [ ] Закон Кулона
- [ ] Формула Томсона

:::explanation
Произведения скаляра на вектор встречаются в физике всюду: $\vec{s} = \vec{v}t$, $\vec{p} = m\vec{v}$, $\vec{F} = q\vec{E}$. Импульс $\vec{p} = m\vec{v}$ как раз пример такого умножения.
:::
:::

:::question{type=single}
Как действует электрическое поле на отрицательный заряд?

- [x] Сила направлена противоположно вектору напряжённости: $\vec{F} = q\vec{E}$, а $q < 0$
- [ ] Сила направлена по полю
- [ ] Сила равна нулю
- [ ] Сила не зависит от знака заряда

:::explanation
Скаляр, умножаемый на вектор, может быть отрицательным: при $q < 0$ вектор $\vec{F} = q\vec{E}$ меняет направление на противоположное.
:::
:::

:::question{type=single}
В каких пределах изменяется угол между векторами?

- [x] От 0 до 180°
- [ ] От 0 до 90°
- [ ] От 0 до 360°
- [ ] От −90° до 90°

:::explanation
Угол между векторами — это угол между их направлениями: лучами, выходящими из общего начала. Он принимает значения от 0 до 180°.
:::
:::

:::question{type=single}
Что такое ось?

- [x] Прямая, снабжённая направлением
- [ ] Отрезок с масштабом
- [ ] Вектор единичной длины
- [ ] Линия без направления

:::explanation
Ось — прямая с направлением, как привычные координатные оси. Угол между вектором и осью определяется так же, как угол между векторами.
:::
:::

:::question{type=single}
По какой формуле вычисляется проекция вектора на ось?

- [x] $a_x = a\cos\varphi$, где $\varphi$ — угол между вектором и осью
- [ ] $a_x = a\sin\varphi$
- [ ] $a_x = a\operatorname{tg}\varphi$
- [ ] $a_x = 1/a$

:::explanation
При остром угле проекция положительна, при тупом — отрицательна (косинус отрицателен), при прямом — равна нулю. Одна формула охватывает все три случая.
:::
:::

:::question{type=single}
Какой знак имеет проекция вектора на ось при тупом угле между вектором и осью?

- [x] Отрицательный
- [ ] Положительный
- [ ] Нулевой
- [ ] Знак произволен

:::explanation
Проекция равна длине отрезка между основаниями перпендикуляров, взятой со знаком: плюс при остром угле, минус при тупом, нуль при прямом.
:::
:::

:::question{type=single}
Как найти проекцию вектора, зная координаты его начала $x_1$ и конца $x_2$?

- [x] $a_x = x_2 - x_1$
- [ ] $a_x = x_1 - x_2$
- [ ] $a_x = x_1 + x_2$
- [ ] $a_x = x_1x_2$

:::explanation
Проекция вектора — это всегда разность координат конца и начала: $a_x = x_2 - x_1$. Формула работает при любом знаке проекции.
:::
:::

:::question{type=single}
Чему равна проекция суммы векторов на ось?

- [x] Сумме проекций слагаемых
- [ ] Произведению проекций
- [ ] Полусумме модулей
- [ ] Проекции первого слагаемого

:::explanation
Проекция суммы векторов равна сумме их проекций: это первое свойство проектирования. Второе: проекция вектора $\lambda\vec{a}$ равна $\lambda a_x$.
:::
:::

:::question{type=single}
Чему равна проекция вектора $\lambda\vec{a}$ на ось?

- [x] $\lambda a_x$, где $a_x$ — проекция вектора $\vec{a}$
- [ ] $a_x/\lambda$
- [ ] $|\lambda|a_x$
- [ ] $\lambda + a_x$

:::explanation
Проекция произведения скаляра на вектор равна произведению скаляра на проекцию вектора — при любом знаке $\lambda$.
:::
:::

:::question{type=single}
Как выглядит разложение вектора по базису на плоскости?

- [x] $\vec{a} = a_x\vec{i} + a_y\vec{j}$
- [ ] $\vec{a} = a_x + a_y$
- [ ] $\vec{a} = a_x\vec{i}\vec{j}$
- [ ] $\vec{a} = \sqrt{a_x^2 + a_y^2}$

:::explanation
Векторы $\vec{i}$ и $\vec{j}$ — единичные векторы координатных осей, базис системы координат. Проекции $a_x$ и $a_y$ называются координатами вектора в этом базисе.
:::
:::

:::question{type=single}
Как найти модуль вектора по его проекциям на плоскости?

- [x] $a = \sqrt{a_x^2 + a_y^2}$
- [ ] $a = a_x + a_y$
- [ ] $a = a_x^2 + a_y^2$
- [ ] $a = |a_x| + |a_y|$

:::explanation
По теореме Пифагора. В пространстве аналогично: $a = \sqrt{a_x^2 + a_y^2 + a_z^2}$.
:::
:::

:::question{type=single}
Как определяется скалярное произведение векторов?

- [x] $\vec{a} \cdot \vec{b} = ab\cos\varphi$ — скаляр, равный произведению модулей на косинус угла между векторами
- [ ] $\vec{a} \cdot \vec{b} = ab\sin\varphi$
- [ ] $\vec{a} \cdot \vec{b} = a + b$
- [ ] Скалярное произведение — вектор

:::explanation
Скалярное произведение — скаляр (число с размерностью). Оно равно произведению модулей векторов на косинус угла между ними.
:::
:::

:::question{type=single}
Как через скалярное произведение записывается работа силы?

- [x] $A = \vec{F} \cdot \vec{s} = Fs\cos\alpha$
- [ ] $A = \vec{F} + \vec{s}$
- [ ] $A = Fs\sin\alpha$
- [ ] $A = \frac{F}{s}$

:::explanation
Работа — скалярное произведение силы и перемещения. При $\alpha > 90°$ работа отрицательна; если сила перпендикулярна перемещению, работа равна нулю.
:::
:::

:::question{type=single}
Результатом скалярного произведения является...

- [x] Скаляр
- [ ] Вектор
- [ ] Два числа
- [ ] Единичный вектор

:::explanation
В отличие от векторного сложения и умножения на скаляр, скалярное произведение двух векторов — это число, обладающее размерностью, равной произведению размерностей сомножителей.
:::
:::

:::question{type=single}
Что можно сказать о координатах вектора в базисе $\vec{i}, \vec{j}, \vec{k}$ в пространстве?

- [x] Их три: $\vec{a} = a_x\vec{i} + a_y\vec{j} + a_z\vec{k}$
- [ ] Их две
- [ ] Их одна
- [ ] Вектор в пространстве не раскладывается

:::explanation
В пространстве базис состоит из трёх единичных векторов $\vec{i}$, $\vec{j}$, $\vec{k}$, а разложение имеет вид $\vec{a} = a_x\vec{i} + a_y\vec{j} + a_z\vec{k}$.
:::
