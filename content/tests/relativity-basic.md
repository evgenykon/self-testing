:::question{type=single}
Когда классическая механика Ньютона работает, а когда нет?

- [x] Работает при скоростях, малых по сравнению со скоростью света, и отказывает при скоростях, близких к скорости света
- [ ] Работает всегда, при любых скоростях
- [ ] Работает только для неподвижных тел
- [ ] Никогда не работает при скоростях меньше скорости света

:::explanation
По мере приближения скорости тела к скорости света проявляются релятивистские эффекты: замедление времени, сокращение длины. Их описывает специальная теория относительности, которая при малых скоростях переходит в классическую механику.
:::

:::question{type=single}
Как выглядят преобразования Галилея?

- [x] $x' = x - vt$, $y' = y$, $z' = z$, $t' = t$
- [ ] $x' = x - vt$, $t' = t - \frac{vx}{c^2}$
- [ ] $x' = x + vt$, $t' = t + vt$
- [ ] $x' = x$, $t' = t + vt$

:::explanation
В классической механике время во всех системах отсчёта одинаково ($t' = t$), а координата меняется на $vt$. При этом ускорение, масса и сила — инварианты: они одинаковы во всех инерциальных системах отсчёта.
:::
:::

Эйнштейн обобщил принцип Галилея с механических явлений на все физические явления: никакой опыт — ни механический, ни электромагнитный, ни ядерный — не отличает покой от равномерного прямолинейного движения.
:::

:::question{type=single}
Как формулируется принцип инвариантности скорости света?

- [x] В каждой инерциальной системе отсчёта свет движется в вакууме с одной и той же скоростью, не зависящей от движения источника
- [ ] Скорость света складывается со скоростью источника
- [ ] Скорость света различна в разных направлениях
- [ ] Скорость света зависит от скорости наблюдателя

:::explanation
Поэтому вышеописанный опыт с лампочкой в носовой части звездолёта провести нельзя: скорость света относительно наблюдателя в звездолёте равна $c$, а не $c + v$.
:::
:::

:::question{type=single}
Какова максимальная скорость распространения взаимодействий в природе?

- [ ] 340 м/с
- [x] Скорость света в вакууме $c = 3 \cdot 10^8$ м/с
- [ ] Скорость звука в стали
- [ ] Бесконечность

:::explanation
Классическая механика предполагала мгновенность взаимодействий, но эксперименты показывают: никакой сигнал, никакое тело не может двигаться быстрее $c$. Конечность скорости сигналов — ключевой факт, лежащий в основе СТО.
:::
:::

:::question{type=single}
Чем является классическая механика по отношению к теории относительности?

- [x] Предельным случаем релятивистской механики при скоростях, малых по сравнению со скоростью света
- [ ] Частным случаем квантовой механики
- [ ] Независимой точной теорией
- [ ] Ошибочной теорией, не имеющей области применимости

:::explanation
Формулы классической механики получаются из релятивистских предельным переходом $c \to \infty$. При малых скоростях релятивистские эффекты исчезающе малы, и классическая механика прекрасно работает.
:::
:::

:::question{type=single}
Как по правилу Эйнштейна синхронизируются двое часов, расположенных в разных точках?

- [x] С помощью светового сигнала: часы B в момент прихода сигнала должны показывать $\frac{t_1 + t_2}{2}$
- [ ] С помощью переноса одних часов из одной точки в другую
- [ ] По радио с задержкой
- [ ] Синхронизация вообще невозможна

:::explanation
Из A в B посылается световой сигнал, который отражается и возвращается; часы A в момент отправки показывали $t_1$, в момент возвращения — $t_2$. Часы B синхронны, если в момент прихода сигнала показывают ровно середину промежутка $\frac{t_1 + t_2}{2}$.
:::

:::question{type=single}
Что произойдёт с часами, перенесёнными из точки A в точку B, по сравнению с часами, синхронизированными по правилу Эйнштейна?

- [x] Перенесённые часы отстанут, причём тем сильнее, чем быстрее их двигали
- [ ] Они будут идти точно так же
- [ ] Они уйдут вперёд
- [ ] Они остановятся

:::explanation
Перенос часов не согласуется с правилом Эйнштейна: двигавшиеся часы отстают, и отставание растёт с увеличением скорости переноса. Поэтому синхронизация производится световыми сигналами.
:::

- [ ] Те, которые видит наблюдатель в один момент

- [ ] Те, которые происходят в одной точке пространства

События одновременны, если их «местные времена» совпадают: показания синхронизированных часов в точках событий одинаковы в моменты их наступления.

:::question{type=single}
В центре движущегося вагона происходит световая вспышка. Что можно сказать о приходе света к задней и передней стенкам?

- [x] В системе вагона свет приходит одновременно, а в системе земли — к задней стенке раньше
- [ ] Свет приходит одновременно и в вагоне, и на земле
- [ ] В системе земли свет приходит к передней стенке раньше
- [ ] Свет не достигнет стенок

:::explanation
Задняя стенка движется навстречу сигналу, передняя — удаляется от него. При одинаковой во всех направлениях скорости света земной наблюдатель увидит приход света к задней стенке раньше: одновременность относительна.
:::
:::

:::question{type=single}
Как связаны показания движущихся и покоящихся часов?

- [x] Движущиеся часы идут медленнее: $\tau = \frac{\tau_0}{\sqrt{1 - v^2/c^2}}$
- [ ] Движущиеся часы идут быстрее
- [ ] Часы идут одинаково во всех системах
- [ ] Движущиеся часы останавливаются

:::explanation
$\tau_0$ — собственное время (промежуток между событиями, происходящими в одной точке). По часам системы, в которой часы движутся, проходит большее время $\tau$. При $v = 0{,}999c$ и $\tau_0 = 1$ с получаем $\tau \approx 22{,}4$ с.
:::
:::

:::question{type=single}
Что такое собственное время?

- [x] Время между двумя событиями, происходящими в одной точке пространства в данной системе отсчёта
- [ ] Время, измеренное по земным часам
- [ ] Время между любыми двумя событиями
- [ ] Максимальный промежуток времени между событиями

:::explanation
Собственное время измеряется по одним и тем же часам, покоящимся в точке, где происходят оба события. Оно всегда меньше промежутка времени между этими событиями, измеренного в любой другой системе отсчёта.
:::
:::

:::question{type=single}
Как изменяются размеры тела в направлении его движения?

- [x] Сокращаются: $l = l_0\sqrt{1 - v^2/c^2}$
- [ ] Увеличиваются
- [ ] Не изменяются
- [ ] Сокращаются и вдоль, и поперёк движения

:::explanation
Собственная длина $l_0$ — длина покоящегося стержня. Поперечные размеры при движении не меняются, а продольные сокращаются. Никаких реальных «сжатий» в стержне не происходит — эффект связан с процедурами измерений.
:::
:::

:::question{type=single}
Что происходит с поперечными размерами движущегося тела?

- [x] Они одинаковы в покоящейся и движущейся системах отсчёта
- [ ] Они сокращаются так же, как продольные
- [ ] Они увеличиваются
- [ ] Они зависят от направления скорости

:::explanation
Если бы движущийся поперёк стержень изменял длину, то по принципу относительности у двух наблюдателей получились бы противоречивые выводы. Поэтому поперечные размеры одинаковы, а сокращаются только продольные.
:::
:::

:::question{type=single}
Как называются формулы, пришедшие в СТО на смену преобразованиям Галилея?

- [x] Преобразования Лоренца
- [ ] Преобразования Фурье
- [ ] Преобразования Лежандра
- [ ] Преобразования Эйнштейна–Галилея

:::explanation
В преобразованиях Лоренца время события $t'$ зависит не только от $t$, но и от координаты $x$: $t' = \frac{t - vx/c^2}{\sqrt{1 - v^2/c^2}}$. При $v \ll c$ они переходят в преобразования Галилея.
:::
:::

:::question{type=single}
Как записывается релятивистский закон сложения скоростей?

- [ ] $u = u' + v$
- [x] $u = \frac{u' + v}{1 + \frac{vu'}{c^2}}$
- [ ] $u = \frac{u'v}{c^2}$
- [ ] $u = u' - v$

:::explanation
Подставив $u' = c$, получаем $u = c$: скорость света одинакова во всех системах отсчёта. Классический закон $u = u' + v$ — предельный случай при $v \ll c$.
:::
:::

:::question{type=single}
Что утверждает формула Эйнштейна $E = mc^2$?

- [x] Покоящееся тело массы $m$ обладает энергией покоя $mc^2$
- [ ] Кинетическая энергия тела равна $mc^2$
- [ ] Масса тела растёт с температурой
- [ ] Тело массы $m$ движется со скоростью света

:::explanation
Каждое тело обладает энергией просто потому, что существует. В одном килограмме вещества заключена энергия $9 \cdot 10^{16}$ Дж — столько выделилось бы при сгорании девяти миллионов тонн дерева.
:::
:::

:::question{type=single}
Как связана полная энергия движущегося тела с энергией покоя?

- [x] $E = \frac{mc^2}{\sqrt{1 - v^2/c^2}}$
- [ ] $E = mc^2 - \frac{mv^2}{2}$
- [ ] $E = mv^2$
- [ ] Полная энергия равна энергии покоя

:::explanation
Полная энергия движущегося тела больше энергии покоя. При малых скоростях она сводится к сумме $mc^2 + \frac{mv^2}{2}$ — энергии покоя и обычной кинетической энергии.
:::
:::

:::question{type=single}
Какова скорость массивных тел и безмассовых частиц?

- [x] Скорость массивного тела всегда меньше $c$, безмассовая частица обязана двигаться со скоростью света
- [ ] Массивные тела могут двигаться быстрее света
- [ ] Безмассовые частицы покоятся
- [ ] Все тела движутся со скоростью света

:::explanation
Для массивного тела выражение $\sqrt{1 - v^2/c^2}$ должно быть действительным, поэтому $v < c$. Безмассовая частица (например, фотон) несёт энергию и может существовать только двигаясь со скоростью $c$.
:::
:::

:::question{type=single}
Как записывается релятивистский импульс тела?

- [ ] $\vec{p} = m\vec{v}$
- [x] $\vec{p} = \frac{m\vec{v}}{\sqrt{1 - v^2/c^2}}$
- [ ] $\vec{p} = \frac{mc^2}{\vec{v}}$
- [ ] $\vec{p} = mv^2$

:::explanation
Классическое выражение $m\vec{v}$ не сохраняется при переходах между системами отсчёта. Релятивистский импульс делится на «релятивистский корень» и согласован с законом сохранения импульса.
:::
:::

:::question{type=single}
Какое уравнение в СТО приходит на смену второму закону Ньютона?

- [ ] $ma = F$
- [x] $\frac{dp}{dt} = F$, где $p$ — релятивистский импульс
- [ ] $p = F + v$
- [ ] $m = F/a$

:::explanation
Релятивистское уравнение движения: производная релятивистского импульса по времени равна силе. Под действием постоянной силы скорость растёт всё медленнее и лишь асимптотически стремится к $c$, никогда её не достигая.
:::
:::

:::question{type=single}
Что происходит со скоростью тела под действием постоянной силы в теории относительности?

- [x] Она растёт всё медленнее и асимптотически стремится к скорости света
- [ ] Она растёт линейно без ограничений
- [ ] Она постоянна
- [ ] Она сразу становится равной $c$

:::explanation
Начальный участок графика $v(t)$ почти линеен — работает классическая механика; затем график искривляется и асимптотически приближается к прямой $v = c$. Постоянное ускорение в СТО невозможно.
:::
:::

:::question{type=single}
Физическая величина $\gamma = \frac{1}{\sqrt{1 - v^2/c^2}}$ часто используется в СТО. Какое значение она принимает при обычных скоростях?
