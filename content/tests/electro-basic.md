:::question{type=single}
Каким зарядом обладает электрон?

- [ ] $+1{,}6 \cdot 10^{-19}$ Кл
- [x] $-1{,}6 \cdot 10^{-19}$ Кл
- [ ] Зарядом, равным нулю
- [ ] $-9{,}1 \cdot 10^{-31}$ Кл

:::explanation
Заряд электрона равен $-1{,}6 \cdot 10^{-19}$ Кл, заряд протона — $+1{,}6 \cdot 10^{-19}$ Кл. Величина $e = 1{,}6 \cdot 10^{-19}$ Кл называется элементарным зарядом.
:::
:::

:::question{type=single}
Как взаимодействуют одноимённые и разноимённые заряды?

- [x] Одноимённые отталкиваются, разноимённые притягиваются
- [ ] Одноимённые притягиваются, разноимённые отталкиваются
- [ ] Все заряды только притягиваются
- [ ] Все заряды только отталкиваются

:::explanation
Заряды разных знаков притягиваются, а заряды одного знака отталкиваются. Этим электромагнитное взаимодействие отличается от гравитационного, которое всегда является притяжением.
:::
:::

:::question{type=single}
При натирании шёлком стеклянная палочка заряжается положительно. Как при этом заряжается шёлк?

- [ ] Тоже положительно
- [x] Отрицательно
- [ ] Остаётся нейтральным
- [ ] Заряжается положительно только при трении о шерсть

:::explanation
При электризации трением часть отрицательных зарядов переходит со стекла на шёлк: палочка заряжается положительно, а шёлк — отрицательно. Суммарный заряд при этом сохраняется.
:::
:::

:::question{type=single}
Что происходит с суммарным зарядом тела при электростатической индукции?

- [x] Он остаётся равным нулю, но заряды перераспределяются по телу
- [ ] Он увеличивается
- [ ] Он уменьшается
- [ ] Тело приобретает заряд только одного знака

:::explanation
При электростатической индукции (электризации через влияние) суммарный заряд тела остаётся нулевым, но в одних участках скапливаются положительные заряды, в других — отрицательные.
:::
:::

:::question{type=single}
Что утверждает закон сохранения заряда?

- [x] В замкнутой системе тел алгебраическая сумма зарядов остаётся неизменной
- [ ] Заряд любого тела всегда положителен
- [ ] Заряды могут исчезать
- [ ] Сумма зарядов всегда увеличивается при электризации

:::explanation
В замкнутой системе тел алгебраическая сумма зарядов сохраняется при любых процессах — даже при рождении и превращениях элементарных частиц.
:::
:::

:::question{type=single}
Как записывается закон Кулона для двух точечных зарядов в вакууме?

- [ ] $F = \frac{k q_1 q_2}{r}$
- [x] $F = \frac{k q_1 q_2}{r^2}$
- [ ] $F = k q_1 q_2 r^2$
- [ ] $F = \frac{q_1 q_2}{kr^2}$

:::explanation
Сила взаимодействия двух неподвижных точечных зарядов прямо пропорциональна произведению зарядов и обратно пропорциональна квадрату расстояния между ними: $F = \frac{kq_1q_2}{r^2}$.
:::
:::

:::question{type=single}
Чему равен коэффициент $k$ в законе Кулона в системе СИ?

- [ ] $9 \cdot 10^{6}$ Н·м²/Кл²
- [x] $9 \cdot 10^{9}$ Н·м²/Кл²
- [ ] $9 \cdot 10^{-9}$ Н·м²/Кл²
- [ ] $1{,}6 \cdot 10^{-19}$ Н·м²/Кл²

:::explanation
$k = 9 \cdot 10^9$ Н·м²/Кл², причём $k = \frac{1}{4\pi\varepsilon_0}$, где $\varepsilon_0 = 8{,}85 \cdot 10^{-12}$ Кл²/(Н·м²) — электрическая постоянная.
:::
:::

:::question{type=single}
Какое тело называют точечным зарядом?

- [x] Заряженное тело, размеры которого много меньше других характерных размеров задачи
- [ ] Тело, имеющее заряд, равный элементарному
- [ ] Тело шарообразной формы
- [ ] Любое заряженное тело

:::explanation
Точечный заряд — такая же идеализация, как материальная точка: его размеры пренебрежимо малы по сравнению с расстояниями между зарядами.
:::
:::

:::question{type=single}
Как определяется напряжённость электрического поля?

- [ ] $\vec{E} = q\vec{F}$
- [x] $\vec{E} = \frac{\vec{F}}{q}$, где $q$ — пробный заряд
- [ ] $\vec{E} = \frac{q}{\vec{F}}$
- [ ] $\vec{E} = \frac{W}{q}$

:::explanation
Напряжённость — силовая характеристика поля: отношение силы, действующей на пробный заряд, к величине этого заряда. Измеряется в Н/Кл или В/м.
:::
:::

:::question{type=single}
Куда направлен вектор напряжённости поля положительного точечного заряда?

- [x] От заряда
- [ ] К заряду
- [ ] По окружности вокруг заряда
- [ ] Напряжённость равна нулю

:::explanation
Поле положительного заряда направлено от него, поле отрицательного — к нему. Модуль напряжённости поля точечного заряда: $E = \frac{kq}{\varepsilon r^2}$.
:::
:::

:::question{type=single}
Где начинаются и заканчиваются линии напряжённости электростатического поля?

- [x] Начинаются на положительных зарядах, заканчиваются на отрицательных
- [ ] Начинаются на отрицательных, заканчиваются на положительных
- [ ] Они всегда замкнуты
- [ ] Они не имеют ни начала, ни конца

:::explanation
Линии напряжённости всегда начинаются на положительных зарядах и заканчиваются на отрицательных. Чем гуще расположены линии, тем больше напряжённость поля.
:::
:::

:::question{type=single}
Что такое потенциал электрического поля?

- [ ] Отношение силы к заряду
- [x] Отношение потенциальной энергии заряда в поле к величине этого заряда
- [ ] Работа поля по перемещению заряда
- [ ] Сила, действующая на единичный заряд

:::explanation
$\varphi = \frac{W}{q}$ — энергетическая характеристика поля. Единица потенциала — вольт: $1$ В $= 1$ Дж/Кл.
:::
:::

:::question{type=single}
Как связаны напряжение, разность потенциалов и работа поля?

- [ ] $U = \varphi_2 - \varphi_1$, $A = qU$
- [x] $U = \varphi_1 - \varphi_2$, $A = qU$
- [ ] $U = \varphi_1 + \varphi_2$, $A = q/U$
- [ ] $U = qA$

:::explanation
Напряжение — это разность потенциалов начальной и конечной точек: $U = \varphi_1 - \varphi_2$. Работа поля по перемещению заряда: $A = qU$.
:::
:::

:::question{type=single}
Как связаны напряжение и напряжённость в однородном электрическом поле?

- [ ] $U = \frac{E}{d}$
- [x] $U = Ed$
- [ ] $U = E + d$
- [ ] $U = \frac{d}{E}$

:::explanation
В однородном поле $U = Ed$, где $d$ — расстояние между точками вдоль силовой линии. Отсюда $E = \frac{U}{d}$, поэтому напряжённость измеряют и в В/м.
:::
:::

:::question{type=single}
Как расположены эквипотенциальные поверхности по отношению к линиям напряжённости?

- [x] Перпендикулярно линиям напряжённости
- [ ] Параллельно линиям напряжённости
- [ ] Под углом 45°
- [ ] Они совпадают с линиями напряжённости

:::explanation
Эквипотенциальные поверхности — поверхности равного потенциала. При перемещении заряда по такой поверхности работа поля равна нулю, поэтому она всегда перпендикулярна линиям напряжённости.
:::
:::

:::question{type=single}
Чему равна напряжённость электростатического поля внутри проводника?

- [x] Нулю
- [ ] Она такая же, как снаружи
- [ ] Она максимальна в центре
- [ ] Она зависит от формы проводника

:::explanation
Свободные заряды проводника перераспределяются до тех пор, пока поле внутри не станет равным нулю. Нескомпенсированные заряды располагаются только на поверхности проводника.
:::
:::

:::question{type=single}
На чём основана электростатическая защита?

- [x] На отсутствии поля в полости внутри проводника
- [ ] На высокой прочности металла
- [ ] На нагревании проводника
- [ ] На электризации трением

:::explanation
Поле внутри проводника, в том числе в полости, равно нулю. Поэтому прибор, помещённый в металлический ящик или сетку, защищён от внешних электростатических полей.
:::
:::

:::question{type=single}
Как меняется электрическое поле внутри диэлектрика по сравнению с вакуумом?

- [x] Уменьшается в $\varepsilon$ раз
- [ ] Увеличивается в $\varepsilon$ раз
- [ ] Не меняется
- [ ] Обращается в нуль

:::explanation
Диэлектрик ослабляет поле в $\varepsilon$ раз: $E = \frac{E_0}{\varepsilon}$, где $\varepsilon$ — диэлектрическая проницаемость. Для вакуума $\varepsilon = 1$, для всех остальных веществ $\varepsilon > 1$.
:::
:::

:::question{type=single}
Какие диэлектрики называются полярными?

- [x] Те, молекулы которых являются диполями
- [ ] Те, которые проводят ток
- [ ] Те, у которых $\varepsilon = 1$
- [ ] Все твёрдые диэлектрики

:::explanation
Молекулы полярных диэлектриков (вода, NaCl, спирты) — диполи; во внешнем поле они поворачиваются вдоль линий напряжённости (ориентационная поляризация). У неполярных диэлектриков (керосин, масло, воздух) поляризация электронная — деформация электронных оболочек.
:::
:::

:::question{type=single}
Как определяется электрическая ёмкость конденсатора?

- [ ] $C = qU$
- [x] $C = \frac{q}{U}$
- [ ] $C = \frac{U}{q}$
- [ ] $C = q + U$

:::explanation
Ёмкость — отношение заряда конденсатора к разности потенциалов между обкладками. Единица ёмкости — фарад: $1$ Ф $= 1$ Кл/В.
:::
:::

:::question{type=single}
От чего зависит ёмкость плоского конденсатора?

- [ ] Только от заряда обкладок
- [x] От площади обкладок, расстояния между ними и диэлектрической проницаемости диэлектрика
- [ ] Только от напряжения
- [ ] От материала обкладок

:::explanation
$C = \frac{\varepsilon_0\varepsilon S}{d}$. Заполнение конденсатора диэлектриком увеличивает его ёмкость в $\varepsilon$ раз.
:::
:::

:::question{type=single}
По какой формуле вычисляется энергия заряженного конденсатора?

- [ ] $W = CU$
- [x] $W = \frac{CU^2}{2}$
- [ ] $W = \frac{q}{2C}$
- [ ] $W = qU$

:::explanation
$W = \frac{CU^2}{2} = \frac{qU}{2} = \frac{q^2}{2C}$. Энергия конденсатора — это энергия электрического поля, заключённого между обкладками.
:::
:::

:::question{type=single}
Какое направление принято за направление электрического тока?

- [x] Направление движения положительных зарядов
- [ ] Направление движения электронов
- [ ] Направление от минуса к плюсу
- [ ] Направление движения нейтральных частиц

:::explanation
По соглашению ток течёт от «плюса» к «минусу». В металлах ток создаётся движением свободных электронов, которое направлено противоположно току.
:::
:::

:::question{type=multiple}
Какие действия электрического тока известны?

- [x] Тепловое
- [x] Магнитное
- [x] Химическое
- [ ] Ядерное

:::explanation
Ток нагревает вещество (тепловое действие), создаёт магнитное поле (магнитное действие) и изменяет химический состав электролитов (химическое действие).
:::
:::

:::question{type=single}
Как вычисляется сила тока?

- [ ] $I = qt$
- [x] $I = \frac{q}{t}$
- [ ] $I = \frac{t}{q}$
- [ ] $I = q + t$

:::explanation
Сила тока — заряд, проходящий через поперечное сечение проводника за единицу времени. Единица силы тока — ампер: при токе 1 А за 1 с проходит заряд 1 Кл.
:::
:::

:::question{type=single}
Как формулируется закон Ома для участка цепи?

- [x] Сила тока прямо пропорциональна напряжению и обратно пропорциональна сопротивлению
- [ ] Сила тока прямо пропорциональна сопротивлению
- [ ] Напряжение обратно пропорционально силе тока
- [ ] Сопротивление прямо пропорционально силе тока

:::explanation
$I = \frac{U}{R}$. Сопротивление измеряется в омах: $1$ Ом $= 1$ В/А.
:::
:::

:::question{type=single}
От чего зависит сопротивление проводника?

- [ ] Только от напряжения на его концах
- [x] От длины, площади поперечного сечения и материала проводника
- [ ] Только от силы тока
- [ ] От формы поперечного сечения

:::explanation
$R = \rho\frac{l}{S}$: сопротивление прямо пропорционально длине проводника и обратно пропорционально площади поперечного сечения. $\rho$ — удельное сопротивление вещества.
:::
:::

:::question{type=multiple}
Какие свойства характерны для последовательного соединения проводников?

- [x] Сила тока в проводниках одинакова
- [x] Напряжение на участке равно сумме напряжений на каждом проводнике
- [x] Общее сопротивление равно сумме сопротивлений
- [ ] Напряжение на каждом проводнике одинаково

:::explanation
При последовательном соединении $I = const$, $U = U_1 + U_2$, $R = R_1 + R_2$.
:::
:::

:::question{type=multiple}
Какие свойства характерны для параллельного соединения проводников?

- [x] Напряжение на каждой ветви одинаково
- [x] Сила тока в неразветвлённой части равна сумме токов в ветвях
- [x] Величина, обратная общему сопротивлению, равна сумме обратных сопротивлений ветвей
- [ ] Сила тока в ветвях одинакова

:::explanation
При параллельном соединении $U = const$, $I = I_1 + I_2$, $\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2}$. Для $n$ одинаковых резисторов $R = \frac{R_1}{n}$.
:::
:::

:::question{type=single}
Как вычисляется мощность тока?

- [ ] $P = \frac{U}{I}$
- [x] $P = UI$
- [ ] $P = U + I$
- [ ] $P = \frac{I}{U}$

:::explanation
Мощность тока $P = UI = I^2R = \frac{U^2}{R}$. Работа тока $A = UIt$; мощность — работа, совершаемая за единицу времени.
:::
:::

:::question{type=single}
Как записывается закон Джоуля–Ленца?

- [ ] $Q = IRt$
- [x] $Q = I^2Rt$
- [ ] $Q = \frac{I^2}{R}t$
- [ ] $Q = IR^2t$

:::explanation
Количество теплоты, выделяющееся на участке цепи, пропорционально квадрату силы тока, сопротивлению и времени: $Q = I^2Rt$.
:::
:::

:::question{type=single}
Что такое ЭДС источника тока?

- [ ] Сила, действующая на заряды внутри источника
- [x] Работа сторонних сил по перемещению единичного положительного заряда
- [ ] Напряжение на внешнем резисторе
- [ ] Внутреннее сопротивление источника

:::explanation
$E = \frac{A_{\text{ст}}}{q}$. Закон Ома для полной цепи: $I = \frac{E}{R + r}$, где $r$ — внутреннее сопротивление источника.
:::
:::

:::question{type=single}
Что является носителями свободных зарядов в металлах?

- [x] Свободные электроны
- [ ] Положительные ионы
- [ ] Отрицательные ионы
- [ ] Нейтральные атомы

:::explanation
В узлах кристаллической решётки металла находятся положительные ионы, а пространство между ними заполнено «газом» свободных электронов. Именно они создают ток.
:::
:::

:::question{type=single}
Что доказал опыт Рикке?

- [x] Электрический ток в металлах не сопровождается переносом вещества
- [ ] Ток в металлах создаётся движением ионов
- [ ] Сопротивление металла растёт при нагревании
- [ ] В металлах нет свободных зарядов

:::explanation
В опыте Рикке через прижатые друг к другу медные и алюминиевый цилиндры год пропускали ток. Переноса вещества не обнаружилось, значит, ток создаётся не движением ионов.
:::
:::

:::question{type=single}
Что является носителями заряда в электролитах?

- [x] Положительные и отрицательные ионы
- [ ] Только электроны
- [ ] Только положительные ионы
- [ ] Нейтральные молекулы

:::explanation
В электролитах молекулы распадаются на ионы (электролитическая диссоциация). Положительные ионы движутся к катоду, отрицательные — к аноду. Ток в электролитах сопровождается переносом вещества — электролизом.
:::
:::

:::question{type=single}
Какие заряженные частицы создают ток в газах?

- [x] Электроны, положительные и отрицательные ионы
- [ ] Только электроны
- [ ] Только ионы
- [ ] Нейтральные атомы

:::explanation
Свободные заряды в газе появляются в результате ионизации. Ток в газах — упорядоченное движение электронов, положительных и отрицательных ионов.
:::
:::

- [ ] Примесный атом
- [ ] Пустота между кристаллами

При разрыве ковалентной связи образуется свободный электрон и дырка — вакансия с нескомпенсированным положительным зарядом. Дырки могут перемещаться по кристаллу, создавая дырочную проводимость.

:::question{type=single}

- [ ] Работа магнитного поля

:::question{type=single}
Как формулируется закон электромагнитной индукции Фарадея?

- [ ] ЭДС индукции равна силе тока
- [ ] Магнитный поток создаёт силу Ампера

$E_i = \left|\frac{\Delta\Phi}{\Delta t}\right|$. Индукционный ток возникает только при изменении магнитного потока, пронизывающего контур.

:::question{type=single}

- [ ] Индукционный ток всегда совпадает по направлению с внешним полем
- [ ] Индукционный ток не создаёт магнитного поля
- [ ] Магнитный поток всегда увеличивается

:::explanation
Правило Ленца выражает закон сохранения энергии: если приближать магнит к контуру, контур отталкивается, а если удалять — притягивается.

:::question{type=single}

- [ ] Ёмкость катушки
- [ ] Сопротивление катушки
- [ ] ЭДС самоиндукции

$\Phi = LI$, единица индуктивности — генри (Гн). При изменении тока в контуре возникает ЭДС самоиндукции $E_i = -L\frac{\Delta I}{\Delta t}$, а энергия магнитного поля катушки равна $\frac{LI^2}{2}$.

- [ ] Из конденсатора и резистора

:::question{type=single}
Как связано напряжение на обмотках трансформатора с числом витков?

- [x] $\frac{U_1}{U_2} = \frac{N_1}{N_2}$
- [ ] $\frac{U_1}{U_2} = \frac{N_2}{N_1}$
- [ ] $U_1U_2 = N_1N_2$
- [ ] Напряжение не зависит от числа витков

:::explanation
Коэффициент трансформации $k = \frac{N_1}{N_2}$. При $k > 1$ трансформатор понижающий, при $k < 1$ — повышающий. Переменное напряжение удобно повышать и понижать, поэтому электроэнергию передают на высоком напряжении.
