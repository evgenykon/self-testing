Какие утверждения об интенсивности волны верны?

- [x] Интенсивность пропорциональна квадрату амплитуды колебаний
- [x] Интенсивность сферической волны обратно пропорциональна квадрату расстояния до источника
- [ ] Амплитуда сферической волны не зависит от расстояния
- [ ] Интенсивность измеряется в джоулях

:::explanation
$I \sim A^2$, причём $A \sim \sqrt{I}$. В сферической волне энергия распределяется по сфере площади $4\pi r^2$, поэтому $I \sim \frac{1}{r^2}$, а амплитуда $A \sim \frac{1}{r}$. Измеряется интенсивность в Вт/м².
:::

Каким параксиальным лучам соответствуют правила построения изображений в собирающей линзе?

- [x] Луч через оптический центр не преломляется
- [x] Луч, параллельный главной оптической оси, идёт через фокус
- [x] Наклонный луч идёт через соответствующий побочный фокус
- [ ] Любой луч идёт через оба фокуса

:::explanation
Три правила хода лучей: через оптический центр — без преломления; параллельный оси — через главный фокус; наклонный — через побочный фокус, отвечающий параллельной ему побочной оси.
:::
:::

:::question{type=single}
Почему диапроектор требует вставлять слайд перевёрнутым?

- [x] Линза проектора даёт действительное перевёрнутое увеличенное изображение
- [ ] Слайд вставляется произвольно
- [ ] Линза даёт прямое изображение
- [ ] Плёнка чувствительна к ориентации

:::explanation
При $f < a < 2f$ собирающая линза даёт действительное, перевёрнутое, увеличенное изображение. Чтобы на экране картинка не оказалась вверх ногами, слайд вставляют перевёрнутым.
:::
:::

:::question{type=single}
Где находится изображение предмета, расположенного в фокальной плоскости собирающей линзы?

- [x] На бесконечности — выходящие лучи параллельны
- [ ] В двойном фокусе
- [ ] В оптическом центре
- [ ] В фокальной плоскости с другой стороны

:::explanation
При $a = f$ лучи источника, лежащего в фокальной плоскости, после линзы идут параллельно друг другу. Изображения нет — или, что то же самое, оно бесконечно удалено.
