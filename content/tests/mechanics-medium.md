Какая формула выражает центростремительное ускорение при движении по окружности радиуса $R$ со скоростью $v$?

:::question{type=single}
Как меняется вес тела в лифте, который движется вверх с ускорением?

- [ ] Уменьшается: $P = m(g - a)$
- [x] Увеличивается: $P = m(g + a)$
- [ ] Не меняется: $P = mg$
- [ ] Становится равным нулю

:::explanation
Когда ускорение направлено вверх, опора давит на тело сильнее: $P = m(g + a)$. Такое состояние называют перегрузкой. При движении вниз с ускорением вес, наоборот, меньше $mg$.
:::
:::

:::question{type=single}
Тележка массой 2 кг движется со скоростью 3 м/с и сталкивается с неподвижной тележкой массой 1 кг. После столкновения тележки сцепляются и движутся вместе. С какой скоростью?

- [ ] 3 м/с
- [x] 2 м/с
- [ ] 1,5 м/с
- [ ] 6 м/с

:::explanation
По закону сохранения импульса $m_1v_1 = (m_1 + m_2)v$, откуда $v = \frac{2 \cdot 3}{3} = 2$ м/с. Импульс системы сохраняется, а часть кинетической энергии переходит во внутреннюю.
:::

:::question{type=multiple}
Какие утверждения о механической энергии верны?

- [x] Кинетическая энергия зависит от массы и скорости тела
- [x] Полная механическая энергия замкнутой системы сохраняется, если нет сил трения
- [ ] Потенциальная энергия тела всегда равна нулю у поверхности Земли
- [ ] При наличии трения механическая энергия полностью сохраняется

:::explanation
$E_k = \frac{mv^2}{2}$ зависит от массы и скорости. Без трения и внешних сил полная механическая энергия сохраняется: потенциальная переходит в кинетическую и обратно. Сила трения переводит механическую энергию во внутреннюю, поэтому с трением она убывает.
:::
