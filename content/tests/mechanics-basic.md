:::question{type=single}
Что изучает механика?

- [ ] Тепловые явления в телах
- [x] Механическое движение тел и их взаимодействие
- [ ] Химические превращения веществ
- [ ] Строение атомов и молекул

:::explanation
Механика — раздел физики, который изучает механическое движение (изменение положения тела в пространстве) и взаимодействия тел, то есть силы.
:::
:::

:::question{type=single}
Бегун пробежал один круг по стадиону и вернулся в стартовую точку. Что можно сказать о пути и перемещении?

- [x] Путь равен длине круга, перемещение равно нулю
- [ ] Путь равен нулю, перемещение равно длине круга
- [ ] И путь, и перемещение равны длине круга
- [ ] И путь, и перемещение равны нулю

:::explanation
Путь — длина траектории, он неотрицателен. Перемещение — вектор, соединяющий начальное и конечное положение; бегун вернулся в исходную точку, поэтому перемещение равно нулю.
:::
:::

:::question{type=single}
Что такое свободное падение?

- [ ] Падение тела в воздухе с раскрытым парашютом
- [x] Движение тела только под действием силы тяжести
- [ ] Движение тела по горизонтали
- [ ] Любое падение с постоянной скоростью

:::question{type=single}
Что происходит с телом, если на него не действуют другие тела?

- [x] Оно сохраняет покой или равномерное прямолинейное движение
- [ ] Оно обязательно останавливается
- [ ] Оно движется с постоянным ускорением
- [ ] Оно всегда падает на Землю

:::explanation
Это первый закон Ньютона (закон инерции). Он выполняется в инерциальных системах отсчёта — системах, связанных с Землёй или движущихся относительно неё равномерно и прямолинейно.
:::
:::

:::question{type=single}
Как записывается второй закон Ньютона?

- [ ] $F = mv$
- [x] $F = ma$
- [ ] $F = \frac{m}{a}$
- [ ] $F = \frac{a}{m}$

Ускорение прямо пропорционально равнодействующей силе и обратно пропорционально массе: $a = \frac{F}{m}$, то есть $F = ma$.

:::question{type=multiple}
Какие из перечисленных величин — векторные?

- [x] Сила
- [x] Скорость
- [ ] Масса
- [ ] Путь

:::explanation
Векторные величины характеризуются не только числом, но и направлением: это сила и скорость. Масса и путь — скаляры.
:::
:::

:::question{type=single}
По какой формуле вычисляется сила тяжести?

- [x] $F = mg$
- [ ] $F = kx$
- [ ] $F = \mu N$
- [ ] $F = \rho g V$

:::explanation
Сила тяжести пропорциональна массе тела: $F = mg$, направлена вертикально вниз, к центру Земли.
:::
:::

:::question{type=single}
Чем вес тела отличается от силы тяжести?

- [ ] Ничем, это одна и та же сила
- [x] Вес — сила, с которой тело действует на опору или подвес, а сила тяжести приложена к самому телу
- [ ] Вес приложен к телу, а сила тяжести — к опоре
- [ ] Вес измеряется в килограммах

:::explanation
Сила тяжести приложена к телу со стороны Земли, а вес — к опоре или подвесу. В покое на горизонтальной опоре $P = mg$, но при ускорении опоры вес меняется.
:::
:::

:::question{type=single}
Как записывается закон Гука?

- [ ] $F = ma$
- [x] $F = kx$
- [ ] $F = mg$
- [ ] $F = \mu N$

:::explanation
Сила упругости пропорциональна деформации: $F = kx$, где $k$ — жёсткость (Н/м), $x$ — удлинение. В векторной форме $F = -kx$: сила направлена против смещения.
:::
:::

:::question{type=single}
Куда направлена сила трения скольжения при движении тела по поверхности?

- [x] Против относительного смещения тела
- [ ] По направлению движения тела
- [ ] Вертикально вверх
- [ ] К центру поверхности

:::explanation
Сила трения всегда направлена против относительного смещения соприкасающихся поверхностей. Она не зависит от площади контакта и пропорциональна силе нормального давления.
:::
:::

:::question{type=single}
По какой формуле вычисляется давление?

- [ ] $p = FS$
- [x] $p = \frac{F}{S}$
- [ ] $p = \frac{S}{F}$
- [ ] $p = F + S$

:::explanation
Давление — отношение силы, действующей перпендикулярно поверхности, к площади этой поверхности: $p = \frac{F}{S}$. В СИ измеряется в паскалях: 1 Па = 1 Н/м².
:::
:::

:::question{type=single}
От чего зависит сила Архимеда?

- [ ] Только от массы тела
- [x] От плотности жидкости и объёма погруженной части тела
- [ ] От плотности материала тела и его массы
- [ ] Только от глубины погружения

:::explanation
$F_A = \rho_{\text{ж}} g V_{\text{погр}}$: выталкивающая сила равна весу вытесненной жидкости. От плотности самого тела она не зависит.
:::
:::

:::question{type=single}
При каком условии тело плавает на поверхности жидкости?

- [x] Если средняя плотность тела не больше плотности жидкости
- [ ] Если плотность тела больше плотности жидкости
- [ ] Если масса тела больше массы жидкости в сосуде
- [ ] Если сила тяжести больше силы Архимеда

:::explanation
Тело плавает, когда сила тяжести уравновешена силой Архимеда. Для этого средняя плотность тела должна быть не больше плотности жидкости: $\rho_{\text{т}} \le \rho_{\text{ж}}$.
:::
:::

:::question{type=single}
Импульс тела вычисляется по формуле...

- [x] $p = mv$
- [ ] $p = ma$
- [ ] $p = \frac{mv^2}{2}$
- [ ] $p = Fs$

:::explanation
Импульс тела — произведение массы на скорость: $p = mv$. Это векторная величина, направленная так же, как скорость; измеряется в кг·м/с.
:::
:::

:::question{type=single}
Что сохраняется в замкнутой системе тел?

- [ ] Импульс каждого тела в отдельности
- [x] Векторная сумма импульсов всех тел системы
- [ ] Кинетическая энергия каждого тела
- [ ] Сумма сил, действующих на тела

:::explanation
Закон сохранения импульса: в замкнутой системе векторная сумма импульсов тел постоянна — при взаимодействиях импульс лишь перераспределяется между телами.
:::
:::

:::question{type=single}
Кинетическая энергия тела вычисляется по формуле...

- [ ] $mv$
- [ ] $mgh$
- [x] $\frac{mv^2}{2}$
- [ ] $Fs$

:::explanation
Кинетическая энергия — энергия движения: $E_k = \frac{mv^2}{2}$. Потенциальная энергия тела в поле тяжести равна $mgh$.
:::
:::

:::question{type=single}
Потенциальная энергия тела, поднятого над Землёй, равна...

- [ ] $\frac{mv^2}{2}$
- [x] $mgh$
- [ ] $\frac{kx^2}{2}$
- [ ] $mg$

:::explanation
$E_p = mgh$ — энергия взаимодействия тела с Землёй; высота $h$ отсчитывается от выбранного уровня. Энергия сжатой пружины равна $\frac{kx^2}{2}$.
:::
:::

:::question{type=single}
От чего зависит период малых колебаний математического маятника?

- [ ] От массы груза и амплитуды
- [x] От длины нити и ускорения свободного падения
- [ ] Только от массы груза
- [ ] Только от амплитуды колебаний

:::explanation
Период малых колебаний математического маятника равен $T = 2\pi\sqrt{\frac{l}{g}}$: он зависит от длины нити и $g$, но не от массы груза и амплитуды.
:::
:::

:::question{type=multiple}
Какие утверждения о механических волнах верны?

- [x] Волна переносит энергию, но не переносит вещество
- [x] Звук в воздухе — продольная волна
- [ ] Волна переносит частицы среды от источника к приёмнику
- [ ] Поперечные волны распространяются в газах

:::explanation
Частицы среды колеблются около положений равновесия, поэтому переносится энергия, а не вещество. Звук в воздухе — продольная волна. Поперечные волны возможны только в твёрдых телах, где есть упругость на сдвиг.
:::
:::
