:::question{type=multiple}
Какие утверждения входят в основные положения молекулярно-кинетической теории?

- [x] Любое вещество состоит из мельчайших частиц — молекул и атомов
- [x] Частицы вещества находятся в беспорядочном движении, которое никогда не прекращается
- [x] Частицы взаимодействуют друг с другом силами притяжения и отталкивания
- [ ] Частицы вещества покоятся, если тело неподвижно

:::explanation
Основные положения МКТ: вещество состоит из частиц, расположенных дискретно; частицы совершают непрекращающееся тепловое движение; частицы взаимодействуют силами притяжения и отталкивания, зависящими от расстояния.
:::
:::

:::question{type=single}
Что такое атом?

- [ ] Наименьшая частица вещества, состоящая из нескольких атомов
- [x] Наименьшая частица данного химического элемента, сохраняющая его химические свойства
- [ ] Любая частица, видимая в микроскоп
- [ ] Частица, не имеющая массы

:::explanation
Атом — наименьшая частица химического элемента, сохраняющая его химические свойства. Все элементы сведены в таблицу Менделеева.
:::
:::

:::question{type=single}
Что такое молекула?

- [x] Наименьшая частица данного вещества (не являющегося химическим элементом), сохраняющая его химические свойства
- [ ] Наименьшая частица химического элемента
- [ ] Любая частица газа
- [ ] Частица, состоящая только из одинаковых атомов

:::explanation
Молекула состоит из двух или более атомов одного или нескольких химических элементов. Например, молекула воды H₂O состоит из двух атомов водорода и одного атома кислорода.
:::
:::

:::question{type=single}
Какое явление служит наиболее ярким доказательством непрерывного хаотического движения молекул?

- [ ] Тепловое расширение тел
- [x] Броуновское движение
- [ ] Кристаллизация
- [ ] Конвекция

:::explanation
Броуновское движение — непрерывное беспорядочное движение взвешенных в жидкости или газе пылинок. Оно никогда не прекращается и объясняется нескомпенсированными ударами молекул.
:::
:::

:::question{type=single}
В чём причина броуновского движения?

- [x] Нескомпенсированные удары молекул жидкости или газа о взвешенную частицу
- [ ] Притяжение частицы к Земле
- [ ] Конвекционные потоки в жидкости
- [ ] Химические реакции между частицей и жидкостью

:::explanation
Взвешенная частица испытывает удары молекул со всех сторон. Из-за хаотичности движения число ударов с разных сторон различается, поэтому частица описывает сложные зигзагообразные траектории.
:::
:::

:::question{type=single}
Что такое диффузия?

- [ ] Проникновение молекул жидкости сквозь стенки сосуда
- [x] Взаимное проникновение соприкасающихся веществ друг в друга
- [ ] Вылет из жидкости самых быстрых молекул
- [ ] Упорядоченное расположение частиц в кристалле

:::explanation
При диффузии частицы одного вещества проникают в промежутки между частицами другого. Диффузия идёт тем быстрее, чем больше эти промежутки.
:::
:::

:::question{type=single}
В каком агрегатном состоянии диффузия идёт быстрее всего?

- [x] В газах
- [ ] В жидкостях
- [ ] В твёрдых телах
- [ ] Во всех состояниях одинаково

:::explanation
В газах расстояния между частицами много больше размеров самих частиц, поэтому частицы легко проникают в промежутки друг друга — быстрее всего смешиваются именно газы.
:::
:::

:::question{type=single}
Каков порядок размера атома?

- [ ] $10^{-2}$ см
- [ ] $10^{-5}$ см
- [x] $10^{-8}$ см
- [ ] $10^{-12}$ см

:::explanation
Размер атома или небольшой молекулы — порядка $10^{-8}$ см. Такой объект невозможно разглядеть ни в какой оптический микроскоп.
:::
:::

:::question{type=multiple}
Какие свойства характерны для газов?

- [x] Занимают весь предоставленный объём
- [x] Легко сжимаются
- [ ] Практически несжимаемы
- [ ] Сохраняют собственную форму

:::explanation
Силы взаимодействия между молекулами газа на больших расстояниях практически отсутствуют, поэтому газы не имеют ни фиксированной формы, ни фиксированного объёма и легко сжимаются.
:::
:::

:::question{type=single}
Какое свойство характерно для жидкостей?

- [x] Сохраняют объём, но не сохраняют форму
- [ ] Сохраняют и объём, и форму
- [ ] Не сохраняют ни объёма, ни формы
- [ ] Легко сжимаются, как газы

:::explanation
Силы притяжения между частицами жидкости достаточно велики, чтобы сохранять объём, но частицы могут скачками менять положения равновесия, поэтому жидкости текучи и принимают форму сосуда. Жидкости практически несжимаемы.
:::
:::

:::question{type=single}
Где находятся частицы кристаллического твёрдого тела?

- [x] В узлах кристаллической решётки, колеблясь около положений равновесия
- [ ] Свободно перемещаются по всему объёму
- [ ] Непрерывно скачками меняют положение
- [ ] Покоятся абсолютно неподвижно

:::explanation
Частицы твёрдого тела совершают тепловые колебания около узлов кристаллической решётки. Чтобы покинуть узел, частице нужна очень большая энергия, поэтому твёрдое тело сохраняет форму и объём.
:::
:::

:::question{type=single}
По какой формуле вычисляется плотность вещества?

- [ ] $\rho = \frac{V}{m}$
- [x] $\rho = \frac{m}{V}$
- [ ] $\rho = mV$
- [ ] $\rho = \frac{m}{N}$

:::explanation
Плотность — масса единицы объёма: $\rho = \frac{m}{V}$. Полезное следствие: $\rho = m_0 n$, где $m_0$ — масса частицы, $n$ — концентрация.
:::
:::

:::question{type=single}
Что называется концентрацией частиц?

- [ ] Масса одной частицы
- [x] Число частиц в единице объёма
- [ ] Число частиц в одном моле
- [ ] Масса единицы объёма

:::explanation
Концентрация $n = \frac{N}{V}$ — число частиц в единице объёма, измеряется в м⁻³. Масса единицы объёма — это плотность.
:::
:::

:::question{type=single}
Чему равна постоянная Авогадро?

- [ ] $6{,}02 \cdot 10^{-23}$ моль⁻¹
- [x] $6{,}02 \cdot 10^{23}$ моль⁻¹
- [ ] $1{,}38 \cdot 10^{-23}$ Дж/К
- [ ] $8{,}31$ Дж/(моль·К)

:::explanation
В одном моле вещества содержится $6{,}02 \cdot 10^{23}$ частиц — это постоянная Авогадро $N_A$. Число частиц в веществе: $N = \nu N_A$.
:::
:::

:::question{type=input}
Чему равно количество вещества в 36 г воды? Молярная масса воды равна 18 г/моль. Ответ введите числом в молях.

:::accepted
2
:::

:::partial
^2([.,]0+)?\s*(моль|мол[ья])?$
:::

:::explanation
Количество вещества $\nu = \frac{m}{\mu} = \frac{36}{18} = 2$ моль. Масса вещества связана с количеством вещества формулой $m = \mu\nu$.
:::
:::

:::question{type=single}
Чему равна молярная масса газообразного водорода H₂?

- [ ] 1 г/моль
- [x] 2 г/моль
- [ ] 4 г/моль
- [ ] 18 г/моль

:::explanation
Молекула водорода состоит из двух атомов, поэтому его молярная масса 2 г/моль. Гелий — одноатомный газ, у него 4 г/моль. Не забывайте переводить молярную массу в кг/моль при расчётах.
:::
:::

:::question{type=single}
Что такое тепловое равновесие?

- [x] Состояние, при котором все макроскопические параметры системы не меняются со временем
- [ ] Состояние, при котором все частицы системы покоятся
- [ ] Состояние, при котором температура тела равна нулю
- [ ] Состояние, при котором прекращается движение молекул

:::explanation
В тепловом равновесии прекращаются все макроскопические процессы: диффузия, теплопередача, фазовые переходы. Движение молекул при этом не прекращается — равновесие динамическое.
:::
:::

:::question{type=single}
Какая температура соответствует абсолютному нулю?

- [ ] 0 °C
- [ ] −100 °C
- [x] −273,15 °C
- [ ] −373,15 °C

:::explanation
Абсолютному нулю $T = 0$ K соответствует $t = -273{,}15$ °C. Связь абсолютной температуры и температуры по шкале Цельсия: $T = t + 273{,}15$ (в задачах достаточно $T = t + 273$).
:::
:::

:::question{type=input}
Переведите 27 °C в абсолютную температуру. Ответ введите числом в кельвинах.

:::accepted
300
:::

:::partial
^300([.,]0+)?\s*(к|k)?$
:::

:::explanation
$T = t + 273 = 27 + 273 = 300$ K.
:::
:::

:::question{type=single}
Температура газа является мерой...

- [x] средней кинетической энергии его частиц
- [ ] потенциальной энергии взаимодействия частиц
- [ ] массы частиц
- [ ] числа частиц в сосуде

:::explanation
При тепловом равновесии выравниваются средние кинетические энергии частиц газов, а значит, и температуры. Связь даётся формулой $E = \frac{3}{2}kT$, где $k$ — постоянная Больцмана.
:::
:::

:::question{type=single}
Как записывается уравнение Менделеева — Клапейрона?

- [ ] $pV = \frac{m}{\mu}$
- [x] $pV = \nu RT$
- [ ] $p = \frac{2}{3}E$
- [ ] $V = \nu RT$

:::explanation
Уравнение состояния идеального газа $pV = \nu RT$ связывает давление, объём и температуру. Его формы: $pV = \frac{m}{\mu}RT$ и $p = \frac{\rho}{\mu}RT$.
:::
:::

:::question{type=single}
Какая формула выражает основное уравнение МКТ идеального газа?

- [ ] $p = nE$
- [x] $p = \frac{2}{3}nE$
- [ ] $p = \frac{1}{3}nE$
- [ ] $p = 3nE$

:::explanation
Связь давления со средней кинетической энергией частиц: $p = \frac{2}{3}nE$. С учётом $E = \frac{m_0v^2}{2}$ получаются формы $p = \frac{1}{3}m_0nv^2$ и $p = \frac{1}{3}\rho v^2$.
:::
:::

:::question{type=single}
Средняя кинетическая энергия частиц идеального газа равна...

- [ ] $E = kT$
- [x] $E = \frac{3}{2}kT$
- [ ] $E = \frac{2}{3}kT$
- [ ] $E = \frac{mv^2}{2}$

:::explanation
$E = \frac{3}{2}kT$, где $k = 1{,}38 \cdot 10^{-23}$ Дж/К — постоянная Больцмана. Температура — мера средней кинетической энергии частиц.
:::
:::

:::question{type=single}
Изотермический процесс — это процесс, идущий при постоянной...

- [x] температуре
- [ ] давлении
- [ ] объёме
- [ ] массе газа

:::explanation
Изотермический процесс: $T = const$, меняются давление и объём. Он описывается законом Бойля — Мариотта.
:::
:::

:::question{type=single}
Как записывается закон Бойля — Мариотта?

- [ ] $\frac{V}{T} = const$
- [x] $pV = const$
- [ ] $\frac{p}{T} = const$
- [ ] $p = const$

:::explanation
В изотермическом процессе произведение давления газа на его объём постоянно. Давление обратно пропорционально объёму: при увеличении объёма в три раза давление уменьшается в три раза.
:::
:::

:::question{type=single}
При постоянном давлении объём газа прямо пропорционален температуре. Как называется этот закон?

- [ ] Закон Бойля — Мариотта
- [x] Закон Гей-Люссака
- [ ] Закон Шарля
- [ ] Закон Ньютона

:::explanation
Закон Гей-Люссака для изобарного процесса: $\frac{V}{T} = const$, то есть $V = const \cdot T$. Типичный пример — газ под массивным подвижным поршнем.
:::
:::

:::question{type=single}
Как записывается закон Шарля для изохорного процесса?

- [ ] $pV = const$
- [ ] $\frac{V}{T} = const$
- [x] $\frac{p}{T} = const$
- [ ] $\frac{T}{p} = const$

:::explanation
В изохорном процессе объём постоянен, а давление прямо пропорционально температуре: $\frac{p}{T} = const$. Изопроцессы также называют газовыми законами.
:::
:::

:::question{type=single}
Что такое насыщенный пар?

- [x] Пар, находящийся в состоянии динамического равновесия со своей жидкостью
- [ ] Пар, не содержащий примесей
- [ ] Пар, нагретый до температуры кипения
- [ ] Пар, полностью заполнивший сосуд

:::explanation
В состоянии динамического равновесия за единицу времени из жидкости вылетает столько же молекул, сколько возвращается обратно. Давление и плотность насыщенного пара — максимальные при данной температуре.
:::
:::

:::question{type=single}
Что такое относительная влажность воздуха?

- [x] Отношение парциального давления водяного пара к давлению насыщенного пара при той же температуре, выраженное в процентах
- [ ] Плотность водяного пара в воздухе
- [ ] Масса воды в 1 м³ воздуха
- [ ] Давление водяного пара в паскалях

:::explanation
$\varphi = \frac{p}{p_{\text{н}}} \cdot 100\%$. Приближённо отношение давлений равно отношению плотностей: $\varphi = \frac{\rho}{\rho_{\text{н}}} \cdot 100\%$. Влажность измеряют психрометром.
:::
:::
