:::question{type=single}
Какие длины волн занимает диапазон видимого света?

- [ ] 380 нм — 780 нм от красного до фиолетового
- [x] 380 нм — 780 нм от фиолетового до красного
- [ ] 10 нм — 380 нм
- [ ] 780 нм — 1 мм

:::explanation
Видимый свет занимает узкий диапазон примерно от 380 нм (фиолетовый участок спектра) до 780 нм (красный участок). По длине волны: фиолетовый на коротковолновом краю, красный — на длинноволновом.
:::

:::question{type=multiple}
Какие законы лежат в основе геометрической оптики?

- [x] Закон независимости световых лучей
- [x] Закон прямолинейного распространения света
- [x] Закон отражения света
- [x] Закон преломления света
- [ ] Закон дисперсии света

:::explanation
В основе геометрической оптики лежат четыре закона: независимости световых лучей, прямолинейного распространения света, отражения и преломления. Дисперсия — явление волновой оптики, законом геометрической оптики не является.
:::
:::

:::question{type=single}
Как формулируется закон отражения света?

- [ ] Угол отражения больше угла падения
- [x] Угол отражения равен углу падения, причём оба угла отсчитываются от перпендикуляра к поверхности
- [ ] Угол отражения равен углу падения, отсчитываемому от поверхности
- [ ] Угол отражения меньше угла падения

:::explanation
Падающий и отражённый лучи лежат с нормалью в одной плоскости, а угол отражения равен углу падения. Углы отсчитываются от перпендикуляра к поверхности, а не от самой поверхности.
:::
:::

:::question{type=single}
Какое изображение даёт плоское зеркало?

- [x] Мнимое, симметричное предмету относительно плоскости зеркала
- [ ] Действительное, перевёрнутое
- [ ] Действительное, прямое
- [ ] Мнимое, уменьшенное

:::explanation
Отражённые лучи идут так, будто исходят из точки, симметричной источнику. Изображение мнимое: в точке S′ пересекаются не сами лучи, а их мысленные продолжения «в зазеркалье».
:::
:::

:::question{type=single}
Как записывается закон преломления при переходе света из воздуха в среду?

- [ ] $\frac{\sin\beta}{\sin\alpha} = n$
- [x] $\frac{\sin\alpha}{\sin\beta} = n$
- [ ] $\sin\alpha \cdot \sin\beta = n$
- [ ] $\sin\alpha = n\sin\beta$

:::explanation
$\frac{\sin\alpha}{\sin\beta} = n$, где $\alpha$ — угол падения в воздухе, $\beta$ — угол преломления в среде. Поскольку $n > 1$, угол преломления меньше угла падения — луч идёт ближе к нормали.
:::
:::

:::question{type=single}
Чему равны показатели преломления воды и стекла?

- [ ] Воды 1,6, стекла 1,33
- [x] Воды 1,33, стекла 1,6
- [ ] У обоих 1
- [ ] У обоих больше 2

:::explanation
Для воды $n = 1{,}33$, для стекла $n = 1{,}6$. У воздуха $n = 1{,}0003$, поэтому в задачах его показатель преломления полагают равным единице.
:::
:::

:::question{type=single}
Что такое показатель преломления среды?

- [ ] Отношение скорости света в среде к скорости света в вакууме
- [x] Отношение скорости света в вакууме к скорости света в среде
- [ ] Скорость света в среде
- [ ] Произведение скорости света на длину волны

:::explanation
$n = \frac{c}{v}$: скорость света в среде меньше скорости света в вакууме, поэтому $n > 1$ для любой среды, кроме вакуума.
:::
:::

:::question{type=single}
Переходя из воздуха в стекло, преломлённый луч...

- [x] Идёт ближе к нормали (угол преломления меньше угла падения)
- [ ] Идёт дальше от нормали
- [ ] Не меняет направления
- [ ] Всегда отражается назад

:::explanation
Стекло оптически более плотно, чем воздух, поэтому $\beta < \alpha$: луч приближается к нормали. Обратное верно при переходе из более плотной среды в менее плотную.
:::
:::

:::question{type=single}
Что утверждает принцип обратимости световых лучей?

- [x] Траектория луча не зависит от того, в прямом или обратном направлении распространяется свет
- [ ] Луч всегда распространяется от источника к глазу
- [ ] Отражённый луч всегда параллелен падающему
- [ ] Свет можно обратить только в вакууме

:::explanation
Двигаясь в обратном направлении, луч пойдёт в точности по тому же пути, что и в прямом направлении. Этот принцип широко используется при построении хода лучей в линзах.
:::
:::

:::question{type=single}
При каком условии наблюдается полное внутреннее отражение?

- [x] Свет переходит из оптически более плотной среды в менее плотную, и угол падения превышает предельный
- [ ] Свет переходит из воздуха в стекло
- [ ] Угол падения меньше предельного угла
- [ ] Свет падает перпендикулярно поверхности

:::explanation
Полное внутреннее отражение возможно только при переходе из оптически более плотной среды в менее плотную. При углах падения, больших предельного $\alpha_0$, преломлённый луч исчезает, и вся энергия отражается. Предельный угол находится из условия $\sin\alpha_0 = \frac{1}{n}$.
:::
:::

:::question{type=single}
Чему приблизительно равен предельный угол полного отражения для воды?

- [ ] 30°
- [x] 48,8°
- [ ] 60°
- [ ] 90°

:::explanation
$\alpha_0 = \arcsin\frac{1}{n} = \arcsin\frac{1}{1{,}33} \approx 48{,}8°$. Именно поэтому поверхность воды при взгляде снизу блестит как зеркало.

- [ ] Любая линза из стекла
- [ ] Линза с плоскими поверхностями

:::explanation
Двояковыпуклая линза после преломления собирает параллельный пучок приблизительно в одной точке — фокусе. Также собирающими являются плосковыпуклая и вогнуто-выпуклая линзы.
:::
:::

:::

Как идёт луч, проходящий через оптический центр тонкой линзы?

- [ ] Через оптический центр
- [ ] Параллельно главной оптической оси
- [ ] Через побочный фокус

Пучок лучей, параллельных главной оптической оси, собирается в главном фокусе линзы. По обратимости, луч из фокуса выйдет из линзы параллельно оси.

:::question{type=single}
Как выглядит формула тонкой линзы?

- [ ] $\frac{1}{a} + \frac{1}{b} = f$
- [x] $\frac{1}{a} + \frac{1}{b} = \frac{1}{f}$
- [ ] $\frac{1}{a} - \frac{1}{b} = \frac{1}{f}$
- [ ] $ab = f$

:::explanation
Формула тонкой линзы: $\frac{1}{a} + \frac{1}{b} = \frac{1}{f}$, где $a$ — расстояние от предмета до линзы, $b$ — от линзы до изображения. Для мнимого изображения $b$ отрицательно, для рассеивающей линзы $f$ отрицательно.
:::
:::

:::question{type=single}
Как вычисляется линейное увеличение линзы?

- [ ] $\Gamma = ab$
- [x] $\Gamma = \frac{b}{a}$
- [ ] $\Gamma = \frac{a}{b}$
- [ ] $\Gamma = \frac{f}{a}$

:::explanation
Линейное увеличение — отношение размера изображения к размеру предмета: $\Gamma = \frac{A'B'}{AB} = \frac{b}{a}$.
:::
:::

:::question{type=single}
Предмет находится от собирающей линзы дальше двойного фокуса ($a > 2f$). Каким будет изображение?

- [x] Действительным, перевёрнутым, уменьшенным
- [ ] Мнимым, прямым, увеличенным
- [ ] Действительным, перевёрнутым, увеличенным
- [ ] Действительным, прямым, равным предмету

:::explanation
При $a > 2f$ изображение действительное, перевёрнутое и уменьшенное. Так работает фотоаппарат: изображение удалённых объектов получается уменьшенным.
:::
:::

:::question{type=single}
Предмет находится между собирающей линзой и её фокусом ($a < f$). Каким будет изображение?

- [x] Мнимым, прямым, увеличенным
- [ ] Действительным, перевёрнутым, уменьшенным
- [ ] Действительным, прямым, увеличенным
- [ ] Действительным, перевёрнутым, увеличенным

:::explanation
При $a < f$ лучи после линзы расходятся, и их продолжения пересекаются за линзой. Изображение мнимое, прямое, увеличенное — именно так работает лупа.
:::
:::

:::question{type=single}
Какое изображение даёт рассеивающая линза при любом положении предмета?

- [x] Мнимое, прямое, уменьшенное
- [ ] Действительное, перевёрнутое, уменьшенное
- [ ] Действительное, прямое, увеличенное
- [ ] Мнимое, перевёрнутое, увеличенное

:::explanation
У рассеивающей линзы качественно иная ситуация всего одна: продолжения расходящихся лучей пересекаются между линзой и предметом, и изображение всегда мнимое, прямое, уменьшенное.
:::
:::

:::question{type=single}
Чем действительное изображение отличается от мнимого?

- [x] Действительное можно получить на экране, мнимое — нельзя
- [ ] Мнимое можно получить на экране, действительное — нельзя
- [ ] Они различаются только размерами
- [ ] Действительное изображение всегда увеличено

:::explanation
В точке действительного изображения пересекаются сами лучи и концентрируется световая энергия, поэтому его можно получить на экране. Мнимое изображение — результат пересечения продолжений лучей, оно существует лишь в нашем сознании.
:::
:::

:::question{type=single}
Каким является изображение предмета на сетчатке глаза?

- [x] Действительным, перевёрнутым, уменьшенным
- [ ] Мнимым, прямым, увеличенным
- [ ] Действительным, прямым, равным предмету
- [ ] Мнимым, перевёрнутым, уменьшенным

:::explanation
На сетчатке лучи должны пересекаться, поэтому изображение действительное. Оно уменьшенное и перевёрнутое, но кора головного мозга «переворачивает» картинку обратно, и мы видим мир правильно.
:::
:::

- [ ] Плоскопараллельными
- [ ] Очками с призмами

- [x] Собирающими

- [ ] Окулярными

:::explanation

:::

:::question{type=single}
Чему равно увеличение лупы?

- [ ] $\Gamma = \frac{f}{d_0}$
- [x] $\Gamma = \frac{d_0}{f}$
- [ ] $\Gamma = d_0f$
- [ ] $\Gamma = \frac{1}{f}$

$\Gamma = \frac{d_0}{f}$, где $d_0 = 25$ см. Лупа с фокусным расстоянием 5 см даёт увеличение $25/5 = 5$. Верхняя граница увеличения лупы — около 50.
:::
:::

:::question{type=single}
Из каких основных оптических элементов состоит микроскоп?

- [x] Объектива и окуляра — двух собирающих линз
- [ ] Двух рассеивающих линз
- [ ] Собирающей и рассеивающей линз
- [ ] Одной собирающей линзы и зеркала

:::explanation
Объектив даёт увеличенное действительное изображение объекта, а окуляр рассматривает его как лупа. Объектив обращён к объекту, окуляр — к глазу (к оку).
:::
:::

:::question{type=single}
Чем труба Кеплера отличается от трубы Галилея?

- [x] У трубы Кеплера окуляр — собирающая линза, у трубы Галилея — рассеивающая
- [ ] У трубы Кеплера окуляр — рассеивающая линза
- [ ] У трубы Галилея окуляр — собирающая линза
- [ ] Трубы различаются только размерами

:::explanation
Увеличение обеих труб равно $\Gamma = \frac{f_1}{f_2}$. Труба Кеплера даёт перевёрнутое изображение, труба Галилея — прямое, поэтому её применяют в театральных биноклях.
:::
:::

:::question{type=single}

- [ ] Свет распространяется только прямолинейно
- [ ] Волны отражаются только от зеркал

:::question{type=single}

:::question{type=single}
При каком условии когерентные волны гасят друг друга?

- [ ] Разность хода равна целому числу длин волн
- [x] Разность хода равна нечётному числу длин полуволн
- [ ] Разность хода превышает длину волны
- [ ] Разность хода меньше длины волны

:::explanation
Минимум: $\delta = n\lambda + \frac{\lambda}{2} = (2n+1)\frac{\lambda}{2}$. Волны приходят в противофазе, гасят друг друга, амплитуда и интенсивность в точке равны нулю.
:::
:::

:::question{type=single}
Что такое дифракция света?

- [x] Огибание волной препятствий и проникновение в область геометрической тени
- [ ] Разложение света в спектр
- [ ] Отражение света от препятствий
- [ ] Поглощение света веществом

:::explanation
Дифракция — отклонение волны от прямолинейного распространения, не сводящееся к отражению или преломлению. Она тем заметнее, чем меньше препятствие по сравнению с длиной волны.
:::
:::

:::question{type=single}
По какой формуле находятся главные максимумы дифракционной решётки?

- [ ] $d\cos\phi = k\lambda$
- [x] $d\sin\phi = k\lambda$
- [ ] $d\sin\phi = (k + \frac{1}{2})\lambda$
- [ ] $d\phi = k\lambda$

:::explanation
$d\sin\phi = k\lambda$, где $d$ — период решётки, $k = 0, 1, 2, \ldots$ — порядок максимума. При $k = 0$ имеем центральный максимум.
:::
:::

:::question{type=single}
Что такое дисперсия света?

- [x] Зависимость показателя преломления среды от частоты света
- [ ] Разложение света на лучи
- [ ] Интерференция света в плёнках
- [ ] Отклонение света у края препятствия

:::explanation
Из-за дисперсии красный свет преломляется в стекле слабее всего, фиолетовый — сильнее всего: показатель преломления растёт с частотой.
:::
:::

:::question{type=single}
Что показал опыт Ньютона с призмой?

- [x] Белый свет является смесью световых пучков различных цветов
- [ ] Свет является потоком частиц
- [ ] Свет распространяется мгновенно
- [ ] Призма усиливает свет

:::explanation
Призма разложила белый свет на непрерывный спектр от красного до фиолетового. Компоненты радуги простейшие: повторно пропущенные через призму, они не меняют цвет, а собранные вместе снова дают белый свет.
:::
