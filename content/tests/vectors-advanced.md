- [x] Проектируют обе части на выбранные оси, перенося операции через равенство, и заменяют векторы их проекциями

:::question{type=single}

:::question{type=single}
Чему равны скалярные произведения базисных векторов $\vec{i}\cdot\vec{j}$ и $\vec{i}\cdot\vec{i}$?

- [x] Соответственно 0 и 1
- [ ] Соответственно 1 и 0
- [ ] Оба равны 1
- [ ] Оба равны 0

:::explanation
$\vec{i}\cdot\vec{i} = 1 \cdot 1 \cdot \cos 0° = 1$, а перпендикулярные векторы дают $\vec{i}\cdot\vec{j} = \cos 90° = 0$. На этом основана координатная формула скалярного произведения.
:::
:::

:::question{type=single}
Как через скалярное произведение выражается мощность силы?

- [x] $P = \vec{F} \cdot \vec{v}$
- [ ] $P = \vec{F} + \vec{v}$
- [ ] $P = F^2v^2$
- [ ] $P = \frac{F}{v}$

:::explanation
При равномерном прямолинейном движении $\vec{s} = \vec{v}t$, поэтому $A = \vec{F}\cdot\vec{v}\,t$, и после деления на $t$ получаем $P = \vec{F}\cdot\vec{v}$.
:::
:::

:::question{type=single}
Как складываются работы нескольких сил?

- [x] Алгебраически: работа равнодействующей равна сумме работ
- [ ] Векторно
- [ ] Работы равнодействующей нет
- [ ] Работы перемножаются

:::explanation
Силы складываются векторно, а их работы — алгебраически: $(\vec{F}_1 + \vec{F}_2)\cdot\vec{s} = \vec{F}_1\cdot\vec{s} + \vec{F}_2\cdot\vec{s}$. Аналогия: напряжённости полей складываются векторно, а потенциалы — алгебраически.
:::
:::

:::question{type=single}
Как связан скалярный квадрат вектора с его координатами?

- [x] $\vec{a}^2 = a^2 = a_x^2 + a_y^2 + a_z^2$
- [ ] $\vec{a}^2 = a_x + a_y + a_z$
- [ ] $\vec{a}^2 = a_x^2b_x^2$
- [ ] Скалярный квадрат — вектор

:::explanation
Скалярный квадрат вектора равен квадрату его модуля; в координатах он равен сумме квадратов координат — отсюда формула модуля: $a = \sqrt{a_x^2 + a_y^2 + a_z^2}$.
:::

:::question{type=single}
Какой знак имеет скалярное произведение при тупом угле между векторами?

- [x] Отрицательный
- [ ] Положительный
- [ ] Нулевой
- [ ] Произвольный

$\cos\varphi < 0$ при $\varphi > 90°$, поэтому $\vec{a}\cdot\vec{b} < 0$. Соответственно, работа силы, составляющей тупой угол с перемещением, отрицательна.

:::question{type=single}
Почему выражения $(m/(m+M))\cdot\vec{v}$ и $m\vec{v}/(m+M)$ дают один и тот же результат?

- [x] По ассоциативности умножения на скаляр: неважно, умножить вектор на $m$, а результат поделить, или сначала поделить скаляры
- [ ] По коммутативности сложения
- [ ] По дистрибутивности
- [ ] Эти выражения различны

:::explanation
Сначала умножили $\vec{v}$ на $m$ и поделили на $m+M$ — или сначала поделили $m$ на $m+M$ и умножили на $\vec{v}$. Результат одинаков: $\lambda(\mu\vec{a}) = (\lambda\mu)\vec{a}$.
:::
:::

:::question{type=single}
Что такое ось вектора?

- [x] Ось, направление которой совпадает с направлением данного вектора
- [ ] Любая ось на плоскости
- [ ] Ось, перпендикулярная вектору
- [ ] Координатная ось X

:::explanation
Проецируя вектор $\vec{a}$ на ось вектора $\vec{b}$, получаем $a_b = a\cos\varphi$, поэтому $\vec{a}\cdot\vec{b} = a_b b$ — так удобно вычислять скалярное произведение.
:::
:::

:::question{type=single}

- [x] Нет: сложение коммутативно и ассоциативно, результат всегда один
- [ ] Да, зависит от порядка

:::question{type=single}
Когда скалярное произведение двух ненулевых векторов равно нулю?
