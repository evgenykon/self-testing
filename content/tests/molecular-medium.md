:::question{type=input}
Определите количество вещества в 88 г углекислого газа CO₂. Молярная масса CO₂ равна 44 г/моль. Ответ введите числом в молях.

:::accepted
2
:::

:::partial
^2([.,]0+)?\s*(моль|мол[ья])?$
:::

:::question{type=single}
Как изменится средняя квадратическая скорость молекул газа при увеличении абсолютной температуры в 4 раза?

- [ ] Увеличится в 4 раза
- [x] Увеличится в 2 раза
- [ ] Уменьшится в 2 раза
- [ ] Не изменится

:::explanation
Средняя квадратическая скорость $v = \sqrt{\frac{3RT}{\mu}}$ пропорциональна корню из температуры: $\sqrt{4} = 2$, поэтому скорость увеличится в 2 раза.
:::
:::

:::question{type=input}
Газ изотермически сжали с 6 л до 3 л. Начальное давление газа 100 кПа. Найдите конечное давление. Ответ введите числом в кПа.

:::accepted
200
:::

:::partial
^200([.,]0+)?\s*кпа?$
:::

:::explanation
Закон Бойля — Мариотта: $p_1V_1 = p_2V_2$, откуда $p_2 = \frac{p_1V_1}{V_2} = \frac{100 \cdot 6}{3} = 200$ кПа. При уменьшении объёма вдвое давление удваивается.
:::
:::

:::question{type=input}
При постоянном давлении газ нагрели с 300 K до 600 K. Начальный объём газа 2 л. Найдите конечный объём. Ответ введите числом в литрах.

:::accepted
4
:::

:::partial
^4([.,]0+)?\s*л?$
:::

:::explanation
Закон Гей-Люссака: $\frac{V_1}{T_1} = \frac{V_2}{T_2}$, откуда $V_2 = V_1\frac{T_2}{T_1} = 2 \cdot \frac{600}{300} = 4$ л.
:::
:::

:::question{type=input}
При постоянном объёме газ нагрели с 300 K до 400 K. Начальное давление газа 150 кПа. Найдите конечное давление. Ответ введите числом в кПа.

:::accepted
200
:::

:::partial
^200([.,]0+)?\s*кпа?$
:::

:::explanation
Закон Шарля: $\frac{p_1}{T_1} = \frac{p_2}{T_2}$, откуда $p_2 = p_1\frac{T_2}{T_1} = 150 \cdot \frac{400}{300} = 200$ кПа.
:::
:::

:::question{type=input}
Газ при температуре 300 K и давлении 100 кПа занимает объём 2 л. Каким станет его давление, если объём увеличить до 4 л, а температуру повысить до 600 K? Ответ введите числом в кПа.

:::accepted
100
:::

:::partial
^100([.,]0+)?\s*кпа?$
:::

:::explanation
Объединённый газовый закон: $\frac{p_1V_1}{T_1} = \frac{p_2V_2}{T_2}$, откуда $p_2 = \frac{p_1V_1T_2}{T_1V_2} = \frac{100 \cdot 2 \cdot 600}{300 \cdot 4} = 100$ кПа.
:::
:::

:::question{type=single}
От чего зависит внутренняя энергия идеального газа неизменной массы?

- [ ] От объёма и давления
- [x] Только от температуры
- [ ] Только от объёма
- [ ] От формы сосуда

:::explanation
Для одноатомного идеального газа $U = \frac{3}{2}\nu RT$: потенциальная энергия взаимодействия частиц равна нулю, поэтому внутренняя энергия определяется только температурой. У реальных тел она зависит ещё и от объёма.
:::
:::

:::question{type=single}
Какими способами можно изменить внутреннюю энергию тела?

- [x] Совершением механической работы и теплопередачей
- [ ] Только совершением механической работы
- [ ] Только теплопередачей
- [ ] Изменением формы тела без нагрева и работы

:::explanation
Существует ровно два способа изменения внутренней энергии: совершение работы и теплопередача (теплообмен).

:::question{type=multiple}
Какие виды теплопередачи существуют?

- [x] Теплопроводность
- [x] Конвекция
- [x] Тепловое излучение
- [ ] Диффузия

:::explanation
Теплопроводность — перенос энергии за счёт теплового движения частиц; конвекция — перенос потоками вещества в жидкостях и газах; излучение распространяется и в вакууме. Диффузия — не вид теплопередачи.

:::question{type=single}
В изотермическом процессе всё переданное газу тепло идёт...

- [x] на совершение газом работы
- [ ] на изменение внутренней энергии газа
- [ ] на нагревание газа
- [ ] на увеличение потенциальной энергии молекул

:::explanation
При $T = const$ внутренняя энергия идеального газа не меняется: $\Delta U = 0$, поэтому первый закон даёт $Q = A$.
:::

:::question{type=single}
В изохорном процессе всё переданное газу тепло идёт...

- [x] на изменение внутренней энергии газа
- [ ] на совершение газом работы
- [ ] частично на работу, частично на внутреннюю энергию
- [ ] на охлаждение газа

:::explanation
При $V = const$ поршень не перемещается и работа газа равна нулю: $A = 0$, поэтому $Q = \Delta U$.
:::
:::

:::question{type=single}
Адиабатный процесс — это процесс...

- [x] идущий без теплообмена с окружающими телами
- [ ] при постоянной температуре
- [ ] при постоянном давлении
- [ ] при постоянном объёме

:::explanation
Адиабатный процесс идёт в теплоизолированном сосуде (например, в термосе): $Q = 0$, поэтому $A = -\Delta U$. При адиабатном расширении газ охлаждается, при сжатии — нагревается.
:::
:::

:::question{type=multiple}
Какие утверждения о насыщенном паре верны?

- [x] Его давление не зависит от объёма при постоянной температуре
- [x] Его плотность растёт с повышением температуры
- [ ] Для него выполняется закон Бойля — Мариотта
- [ ] Его давление растёт с температурой строго линейно

:::explanation
При изотермическом изменении объёма насыщенного пара часть пара конденсируется или дополнительно испаряется, поэтому плотность и давление возвращаются к прежним значениям — закон Бойля — Мариотта не выполняется. С ростом температуры плотность насыщенного пара растёт, и давление увеличивается быстрее, чем по линейному закону.
:::
